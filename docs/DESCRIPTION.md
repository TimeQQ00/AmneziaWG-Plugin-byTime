# AmneziaWG byTime — краткое описание

**Что это.** Плагин для exteraGram, который поднимает AmneziaWG-туннель прямо
внутри мессенджера и направляет в него трафик Telegram. Без системного VPN,
без root, без отдельных приложений.

**Автор:** Time.

## Одно предложение

Telegram внутри мессенджера общается с вашим AmneziaWG-сервером через
локальный SOCKS5: движок туннеля (Go) скомпилирован под Android и живёт
в процессе exteraGram.

## Что умеет

- **Свои конфиги** — укажите `.conf` (формат AmneziaWG/WireGuard,
  включая обфускацию Jc/Jmin/Jmax, S1–S4, H1–H4, I1–I5): кнопка «Выбрать .conf»
  найдёт файлы в Download/Documents, есть импорт из буфера обмена и ручной путь.
  Конфиг запоминается и используется при каждом старте.
- **Проверка перед переключением** — плагин сначала проверяет, что через туннель
  реально ходит трафик, и только потом объявляет успех.
- **Авто-откат** — если ваш конфиг не заработал, туннель корректно остановится
  с понятным сообщением (а в личной сборке со встроенным конфигом — вернётся
  на встроенный сервер). Ваш конфиг при этом **сохраняется** — разовый сбой
  сети не заставляет импортировать всё заново.
- **Тёплый туннель** — при возврате в приложение поднимает только реально
  умершее соединение, а не переподключается каждый раз.

## Что внутри (2 строки)

Собственный движок `libawgcore.so`: AmneziaWG (amneziawg-go) + userspace-сеть
(gVisor netstack) + локальный SOCKS5 — 7.4 МБ, Android arm64.
Python-часть в exteraGram: загрузка движка, настройки, включение прокси Telegram
через его внутренний API (`SharedConfig`/`ConnectionsManager`).

## Кому нужно

Тем, кто пользуется exteraGram в сетях, где Telegram ограничен, но не хочет
держать включённый системный VPN (или не может — нет прав) и хочет
обфусцированный протокол, устойчивый к блокировкам.

## Чего не делает

- Не туннелирует звонки (UDP через SOCKS5 не ходит).
- Не работает на 32-битных устройствах.
- Не является системным VPN: другое приложение под VPN и этот плагин
  конфликта не создадут, но и остальной телефон через туннель не пойдёт.

## Файл для установки

`amnezia_awg_byTime.plugin` — добавить в exteraGram через «Настройки → Плагины → +».
